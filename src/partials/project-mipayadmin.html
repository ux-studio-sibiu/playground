Mi-Pay Service Desk and Mi-Pay clients (like Vodafone,12Telecom, O2) use this administration dashboard to browse and keep track of their custumers, orders and transactions.

Rejuvenating this piece of software was quite a challange as both UI and backend services were simultaneously overhauled using the previously uncharted .NET Core + Angular 2 stack. Linked below is the wireframe with the initial design for this dashboard.

Front-end highlights:
- complex permissions for each clients set of users
- live search and live filter database entries
- filter state persists via query string, making state-sharing by url posible between users. This also allows for reliable back/forward browser navigation
