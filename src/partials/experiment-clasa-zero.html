Kids Stem Game

  • Random puzzles for pre-school kids
  • In progress.. user testing and improvements with help from my 6y old kid (good for car trips)
  • correct answer is highlighted in this demo, you can turn this off in the settings for a challenge
Features :
  • randomly generated puzzles and possible answers
  • 10+ puzzle types: sequences, matching, counting, simple reading
  • persist settings with local storage
  • custom puzzles can be added on sanity cms
  • ai generated graphics
  • next.js with zustand for state management
  • focus on performance and optimization: smooth transitions, preload next puzzle
  • slide back to review previous puzzles and answers

Stack : react next.js zustand sanity github copilot chat gpt vscode
